# 留言板

一个带登录的公共留言板。第 1 步已完成：**网页能从云端数据库读数据**。

> 这是本项目第一次用到「后端」。前四个项目（个人主页 / 待办清单 / 报错翻译官 / 贪吃蛇）的数据要么写死在代码里，要么只存在你自己浏览器的 localStorage 里 —— **换台电脑打开就没了**。这个项目的数据存在云端，谁打开看到的都是同一份。

## 为什么"登录"必须排在"发留言"前面

我原来的计划是「先做一个不用登录的匿名版，再加登录」。**这个计划被现实推翻了**，原因值得记住：

云端数据库有一道铁律 —— **每一行数据都必须有主人**。表结构里 `owner_id` 这个字段是 `NOT NULL`，而且它的值是服务器根据"当前登录的是谁"自动填的。

结果就是：

- **没登录** → 不知道你是谁 → `owner_id` 填不出来 → **写入被拒绝**
- 登录了 → 服务器知道你是谁 → 自动填上 → 写入成功

所以不是"想不想加登录"的问题，**是这台数据库不接受没有身份的人写数据**。

> 一句话：**「你是谁」在云端是一个必需品，不是一个可选项。**

## 文件结构

| 文件 | 干什么 |
|---|---|
| `index.html` | 骨架：标题 + 留言列表 + 一个「重新读一次」按钮 |
| `style.css` | 皮肤：深色主题，颜色集中在 `:root` |
| `script.js` | 肌肉：建客户端 → 向云端要数据 → 画到页面上 |
| `cloud-config.js` | 云服务的公开配置（应用域名 + 公开标识） |
| `.gitignore` | 把 `.env`、密钥文件拦在仓库外 |

**比前四个项目多出来的两样东西**：

1. **`cloud-config.js`** —— 放"公开配置"。里面的 `publishableKey` 只标识"是哪个应用"，本身不带权限，可以放在源码里（浏览器里本来就看得到）。真正的密钥留在服务器那边，永远不会下发到网页。
2. **一个从 CDN 加载的 sdk**（写在 `index.html` 里）—— 平台给的工具包，负责替你调云端接口。你不用自己拼网络请求。

## 怎么跑

**这个项目不能用双击打开。**

云服务除了一般的登录校验，还有一道额外的门：**它只认自己那个域名的网页。** 网页从哪个域名打开的，它就要求是那个域名，别的地址一律拒绝。

- 本地双击打开 → 页面地址是 `file://…` → 云端拒绝 ❌
- 从公网地址打开 → 地址对得上 → 云端放行 ✅

这是**故意的安全设计**：防止别人把你的网页整个拷走、挂到自己的域名下用。

所以运行方式是：**发布到公网，然后用公网地址打开。** 页面顶部有一条提示条，会把"当前地址"和"要求的地址"都显示出来 —— 以后读不到数据，先看这一行。

## 数据库

云端的表叫 `messages`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT | 主键，自动递增。每一行的唯一编号 |
| `owner_id` | TEXT | **主人是谁**。默认值 `auth.uid()`，由服务器自动填，前端不许传 |
| `owner_name` | TEXT | 展示用的昵称（只为好看，不参与权限判断） |
| `content` | TEXT | 留言内容 |
| `created_at` | TIMESTAMPTZ | 写入时间，服务器自动填 |

**三道门（RLS 行级安全）**：

| 策略 | 管什么 | 规则 |
|---|---|---|
| `messages_read_all` | 谁能读 | **所有人**（含未登录） |
| `messages_insert_own` | 谁能写 | 只有登录的人，且只能以自己的身份写 |
| `messages_delete_own` | 谁能删 | 只有本人能删自己的 |

权限判断发生在**数据库那一层**，不在网页里。也就是说，就算有人把网页代码改掉、硬要删别人的留言，数据库也会拒绝。**网页只是"面子"，数据库才是"里子"。**

## 第 1 步验收

| 该看到的 | 说明 |
|---|---|
| 列表里有 1 条留言，昵称是「云端」 | 这条是**在服务器端直接塞进数据库的**，你的浏览器从来没写过它。你能看到 → 数据确实在云端 |
| 状态行显示「第 1 次读取：拿到 1 条，耗时 XX 毫秒」 | 每次读都真的走了一趟网络 |
| 点「重新读一次」，次数从 1 变成 2 | 证明不是本地缓存 |
| 顶部提示条是**绿色的 ✅**（不是黄色警告） | 说明网页域名和云端要求的域名对上了 |
